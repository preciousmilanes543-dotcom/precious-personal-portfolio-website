# Precious Milanes – Personal Portfolio

A personal portfolio website by Precious G. Milanes.

## Technologies
- HTML: website structure and content
- CSS: layout, responsive styling, and the Original, Blue & Light Blue, and Lavender Light themes
- JavaScript: mobile navigation, gallery lightbox, theme switcher, and automatic footer year

## Files
- `index.html` — complete, self-contained portfolio website. Its CSS, JavaScript, and photos are included in this file, so no separate assets folder is required.

## View locally
Download `index.html` and open it in a web browser such as Google Chrome.

## Publish with GitHub Pages
1. Upload `index.html` and `README.md` to the root of a public GitHub repository.
2. Open the repository's **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/(root)`, then click **Save**.
5. Wait for GitHub Pages to finish publishing. The public website link will appear in the Pages section.

The portfolio is static HTML/CSS/JavaScript and can be hosted by GitHub Pages.
