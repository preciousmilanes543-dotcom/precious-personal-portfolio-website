# Precious Milanes – Personal Portfolio

A personal portfolio website by Precious G. Milanes.

## Technologies Used
- **HTML** (`index.html`) – website structure and content.
- **CSS** (`style.css`) – colors, layout, responsive design, and themes.
- **JavaScript** (`script.js`) – interactive navigation, gallery lightbox, theme switcher, and footer year.

## Project Files
- `index.html` – main webpage.
- `style.css` – website styling.
- `script.js` – interactive features.
- `assets/` – portfolio photos.

## Run Locally
Keep all files and the `assets` folder together. Open `index.html` in a web browser.

## Publish with GitHub Pages
Upload `index.html`, `style.css`, `script.js`, `README.md`, and the complete `assets` folder to the root of a public GitHub repository. In **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
